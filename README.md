# PoolChanger v0.3.0

Local AxeOS/ESP-Miner pool manager for Bitaxe and NerdQaxe miners.

Features:
- LAN discovery by CIDR
- Miner status dashboard
- Primary + fallback pool management
- Failover switch
- Multi-miner pool changes
- Docker / 5tratumOS ready

Start:
`docker compose up -d --build`

Open:
`http://<host>:8090`

Designed for a trusted local network.
